# MSC-RGBT-P05: Transfer detektorów pomiędzy sensorami i domenami

Detection performance may degrade across genuinely independent sensor platforms, viewpoints and thermal domains.

**Status naukowy:** planowany manuskrypt (`PLANNED`). **Tytuł angielski:** *Cross-Sensor and Cross-Domain Transfer of RGB and Long-Wave Infrared Detectors*.

[Źródło roboczego manuskryptu LaTeX](main.tex) zawiera tytuł, streszczenie, pytanie badawcze, plan metodologiczny, wynik główny i granice interpretacji. [Pierwotny materiał badawczy](https://github.com/MatPomGit/arc-rgbt/blob/main/publications/P05/protocol/README.md) pozostaje źródłem szczegółowych założeń i protokołu.

Przypisanie do katalogu programu nie zmienia statusu zatwierdzenia ani nie stanowi potwierdzenia wykonania badań.
