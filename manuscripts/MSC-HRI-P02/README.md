# MSC-HRI-P02: Estymacja świadomości, intencji i adresata interakcji człowiek-humanoid

Badanie rozdziela intencję, świadomość obecności robota i adresata komunikatu, stosując niezależnie oceniane etykiety oraz ablacje kanałów percepcji.

**Status naukowy:** planowany manuskrypt (`PLANNED`). **Tytuł angielski:** *Multimodal Estimation of Human Awareness, Intention, and Addressee for Safety-Critical Human--Humanoid Interaction*.
