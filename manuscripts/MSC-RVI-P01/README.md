# MSC-RVI-P01: Reprodukowany benchmark inspekcji od nominalnych do trudnych scen

Reprodukowany zestaw scen i progów trudności pozwala porównywać metody autonomicznej inspekcji przy stałych warunkach oceny.

**Status naukowy:** planowany manuskrypt (`PLANNED`). **Tytuł angielski:** *Reproducible Simulation Benchmark for Autonomous Robotic Visual Inspection*.

[Kanoniczny manuskrypt LaTeX](https://github.com/MatPomGit/arc-rvi/blob/main/papers/paper01/manuscript.tex) jest utrzymywany w repozytorium projektu źródłowego. Nie powiela się jego źródła w indeksie programu ARC Robo.

Przypisanie do katalogu programu nie zmienia statusu zatwierdzenia ani nie stanowi potwierdzenia wykonania badań.
