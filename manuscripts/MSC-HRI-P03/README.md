# MSC-HRI-P03: Dynamika ładunku i omiatana geometria manipulatora w ocenie kolizji humanoida

Ryzyko kolizji jest modelowane z uwzględnieniem geometrii omiatanej, rozkładu masy ładunku, konfiguracji manipulatora i ruchu obrotowego.
