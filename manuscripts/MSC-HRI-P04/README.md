# MSC-HRI-P04: Kalibracja zasięgalności człowieka pod zmianą rozkładu i ograniczeniami czasu

Projekt bada pokrycie predykcyjnych obszarów zasięgalności przy zmianie rozkładu danych oraz koszt obliczeń i opóźnienia skrajne.

**Status naukowy:** planowany manuskrypt (`PLANNED`). **Tytuł angielski:** *Online Calibration of Probabilistic Human Reachability under Distribution Shift for Real-Time HRI Safety*.

[Kanoniczny manuskrypt LaTeX](https://github.com/MatPomGit/arc-hri-safety/blob/main/manuscripts/04_online_uncertainty_calibration/main.tex) jest utrzymywany w repozytorium projektu źródłowego. Nie powiela się jego źródła w indeksie programu ARC Robo.

Przypisanie do katalogu programu nie zmienia statusu zatwierdzenia ani nie stanowi potwierdzenia wykonania badań.
