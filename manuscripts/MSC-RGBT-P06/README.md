# MSC-RGBT-P06: Śledzenie tożsamości obiektów w obrazie RGB/LWIR

Tracking requires temporal association and independently annotated identities, not frame-level detection accuracy alone.

**Status naukowy:** planowany manuskrypt (`PLANNED`). **Tytuł angielski:** *Identity-Preserving Multi-Object Tracking in RGB and Long-Wave Infrared Video*.

[Źródło roboczego manuskryptu LaTeX](main.tex) zawiera tytuł, streszczenie, pytanie badawcze, plan metodologiczny, wynik główny i granice interpretacji. [Pierwotny materiał badawczy](https://github.com/MatPomGit/arc-rgbt/blob/main/publications/P06/protocol/README.md) pozostaje źródłem szczegółowych założeń i protokołu.

Przypisanie do katalogu programu nie zmienia statusu zatwierdzenia ani nie stanowi potwierdzenia wykonania badań.
