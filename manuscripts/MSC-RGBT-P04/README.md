# MSC-RGBT-P04: Odporność detekcji przy uszkodzonych lub brakujących modalnościach

A sensor fusion model may require explicit failure detection and selective prediction to remain dependable under missing or corrupted modalities.

**Status naukowy:** planowany manuskrypt (`PLANNED`). **Tytuł angielski:** *Failure-Aware RGB and LWIR Object Detection under Missing and Degraded Modalities*.

[Źródło roboczego manuskryptu LaTeX](main.tex) zawiera tytuł, streszczenie, pytanie badawcze, plan metodologiczny, wynik główny i granice interpretacji. [Pierwotny materiał badawczy](https://github.com/MatPomGit/arc-rgbt/blob/main/publications/P04/protocol/README.md) pozostaje źródłem szczegółowych założeń i protokołu.
