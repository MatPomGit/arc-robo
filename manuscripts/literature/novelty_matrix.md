# Bibliografia porównawcza i granice nowości ARC Robo

Wykaz obejmuje 14 prospektywnych planów w wersji 0.3.0. Publikacje zostały sprawdzone według stron wydawców lub oficjalnych repozytoriów konferencyjnych; jest to selektywny, a nie systematyczny przegląd literatury. Każdy tekst pozostaje warunkowy względem szczegółowej analizy stanu wiedzy i niezależnego dowodu wkładu.

| [MSC-RGBT-P04](../MSC-RGBT-P04/main.tex) | [DRNet: Dynamic routing for robust multispectral object detection under modality missing](https://www.sciencedirect.com/science/article/pii/S1051200426005798); [Mitigating Spectral Imbalance and Detail Attenuation in RGB-Thermal Object Detection via Frequency-Guided Multimodal Fusion](https://doi.org/10.3390/s26134145) | Difference in worst-stratum missed-detection risk between failure-aware and fixed-fusion policies at a frozen false-alarm ceiling and minimum accepted prediction coverage. | Select fault strata and minimum coverage on development sequences; report worst-stratum confidence intervals rather than pooled mAP alone. |
| [MSC-RGBT-P05](../MSC-RGBT-P05/main.tex) | [M3OT: A Multi-Drone Multi-Modality dataset for Multi-Object Tracking](https://doi.org/10.1038/s41597-025-06204-0); [Mitigating Spectral Imbalance and Detail Attenuation in RGB-Thermal Object Detection via Frequency-Guided Multimodal Fusion](https://doi.org/10.3390/s26134145) | Target-domain recall difference between bounded adaptation and source-only inference at a fixed false-positive-per-frame operating point. | The primary target must be an independent physical sensor or acquisition cohort with compatible labels; resizing does not count as sensor transfer. |
| [MSC-RGBT-P06](../MSC-RGBT-P06/main.tex) | [M3OT: A Multi-Drone Multi-Modality dataset for Multi-Object Tracking](https://doi.org/10.1038/s41597-025-06204-0); [What You Have is What You Track: Adaptive and Robust Multimodal Tracking](https://openaccess.thecvf.com/content/ICCV2025/html/Tan_What_You_Have_is_What_You_Track_Adaptive_and_Robust_ICCV_2025_paper.html) | Difference in identity switches per eligible annotated object trajectory between two trackers using the identical frozen detections. | ICCV FlexTrack is relevant to missing-modality tracking, but is not a direct multi-object identity-switch benchmark. | [MSC-RGBT-P07](../MSC-RGBT-P07/main.tex) | [SDR-YOLO: Scale-Selective Detail Residual Enhanced YOLO for Visible--Thermal Object Detection](https://www.mdpi.com/2072-4292/18/18/3216); [Adaptive feature fusion and task-dynamic alignment for real-time object detection on edge devices](https://www.sciencedirect.com/science/article/pii/S0957417425019608) | Difference in measured Joules per complete evaluated scene between adaptive sensing and the best feasible fixed sensor mode at matched quality and latency. | Proceed only after fixed-mode P03 measurements and verified real sensor switching. | [MSC-RGBT-P08](../MSC-RGBT-P08/main.tex) | [Autonomous--Targetless Extrinsic Calibration of Thermal, RGB, and LiDAR Sensors](https://doi.org/10.1109/TIM.2024.3480237); [Misaligned Visible-Thermal Object Detection: A Drone-Based Benchmark and Baseline](https://ieeexplore.ieee.org/abstract/document/10522939) | Absolute deviation of observed held-out prediction-bound coverage from a preregistered nominal target for association risk under measured space/time calibration uncertainty. | Quantify interval width alongside empirical coverage to prevent vacuous prediction bounds; independent physical calibration sessions are required. |
| [MSC-RVI-P09](../MSC-RVI-P09/main.tex) | [Transparency improves the accuracy of automation use, but automation confidence information does not](https://doi.org/10.1186/s41235-024-00599-x); [Trust as a design principle in human--robot collaboration](https://doi.org/10.1007/s10462-026-11554-1) | Marginal difference in false acceptance of objectively incomplete inspection missions between evidence-explicit and information-length-controlled status reports. | Use participant/case crossed effects, a prespecified non-inferiority margin for true completion acceptance and an ethics-approved pilot to set precision and sample size. |

| [MSC-S4D-P03](../MSC-S4D-P03/main.tex) | [A Survey of Map Construction and Management Methods for Single Embodied Agents](https://doi.org/10.3390/s26196242); [Integrity-Aware Hierarchical Navigation for UAVs Under GNSS Spoofing and Multi-Sensor Degradation](https://www.mdpi.com/2504-446X/10/10/738) | Paired per-sequence change in predictive occupancy score under joint GNSS/vision degradation at fixed token-memory and compute budgets. | Define H3 as an additive-scale interaction contrast: change in joint degradation minus vision-only change minus GNSS-only change plus undegraded change, all in the same occupancy-score units. |

Przed zgłoszeniem artykułu niezbędny jest dalszy przegląd: zakres wyszukiwania, kryteria doboru, analiza zbieżnych punktów końcowych, aktualne daty publikacji oraz adekwatność testowanych metod. Hipotezy i marginesy bez uzasadnienia empirycznego nie mogą być traktowane jako zamrożone.
