# MSC-RVI-P09: Czy operator rozpozna fałszywie zakończoną misję inspekcji robota dzięki ujawnieniu dowodów?

Operator decisions about mission completion can be tested using inspection reports that either conceal or explicitly expose missing and mismatched visual evidence.
