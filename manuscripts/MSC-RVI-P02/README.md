# MSC-RVI-P02: Odporna lokalizacja właściwego egzemplarza przy dystraktorach

Lokalizacja właściwego egzemplarza obiektu jest oceniana w obecności podobnych obiektów, przesłonięć i zakłóceń identyfikacji.

**Status naukowy:** planowany manuskrypt (`PLANNED`). **Tytuł angielski:** *Robust Instance-Level Object Localization in Multi-Object Environments for Humanoid Robots*.

[Kanoniczny manuskrypt LaTeX](https://github.com/MatPomGit/arc-rvi/blob/main/papers/paper02/manuscript.tex) jest utrzymywany w repozytorium projektu źródłowego. Nie powiela się jego źródła w indeksie programu ARC Robo.
