# MSC-RGBT-P02: Rejestracja ekspozycji i synchronizacja fuzji RGB/IR

Multispectral fusion depends on physically meaningful exposure timing and spatial registration, not merely frame-arrival order.

**Status naukowy:** planowany manuskrypt (`PLANNED`). **Tytuł angielski:** *Exposure-Time Registration and Geometric Synchronization for RGB and Infrared Sensor Fusion*.

[Źródło roboczego manuskryptu LaTeX](main.tex) zawiera tytuł, streszczenie, pytanie badawcze, plan metodologiczny, wynik główny i granice interpretacji. [Wersjonowane źródło zakresu badania](https://github.com/MatPomGit/arc-rgbt/blob/caafa30c7c7421a2e4b14d70871015d7f6bd273e/publications/P02/protocol/README.md) pozostaje źródłem szczegółowych założeń i protokołu.
