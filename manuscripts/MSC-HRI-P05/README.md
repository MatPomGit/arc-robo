# MSC-HRI-P05: Benchmark multimodalnej predykcji bezpieczeństwa HRI

Warunkowy benchmark łączy scenariusze, anotacje, podziały niezależne od prób i metryki wielu zadań bezpieczeństwa.

**Status naukowy:** manuskrypt warunkowy (`CONDITIONAL`). **Tytuł angielski:** *ARC-HRI Benchmark: Multimodal Predictive Safety Evaluation for Human--Humanoid Interaction*.

[Kanoniczny manuskrypt LaTeX](https://github.com/MatPomGit/arc-hri-safety/blob/main/manuscripts/05_multimodal_safety_benchmark/main.tex) jest utrzymywany w repozytorium projektu źródłowego. Nie powiela się jego źródła w indeksie programu ARC Robo.

Przypisanie do katalogu programu nie zmienia statusu zatwierdzenia ani nie stanowi potwierdzenia wykonania badań.
