# MSC-RGBT-P01: Rozdzielczość źródłowa i fizyczne granice detekcji RGB/LWIR

Native sampling density and object footprint impose physical limits on detector recall that should not be confused with interpolation or exported annotation grids.

**Status naukowy:** planowany manuskrypt (`PLANNED`). **Tytuł angielski:** *Source-Resolution and Physical Limits of RGB and Long-Wave Infrared Object Detection*.

[Źródło roboczego manuskryptu LaTeX](main.tex) zawiera tytuł, streszczenie, pytanie badawcze, plan metodologiczny, wynik główny i granice interpretacji. [Wersjonowane źródło zakresu badania](https://github.com/MatPomGit/arc-rgbt/blob/caafa30c7c7421a2e4b14d70871015d7f6bd273e/publications/P01/protocol/README.md) pozostaje źródłem szczegółowych założeń i protokołu.

Przypisanie do katalogu programu nie zmienia statusu zatwierdzenia ani nie stanowi potwierdzenia wykonania badań.
