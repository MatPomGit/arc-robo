# MSC-RGBT-P03: Koszt stałego przetwarzania RGB/LWIR na urządzeniu: pamięć, opóźnienie i energia

Embedded multispectral perception must be evaluated using instrumented end-to-end cost rather than nominal accelerator throughput.

**Status naukowy:** planowany manuskrypt (`PLANNED`). **Tytuł angielski:** *Energy, Latency, and Memory Cost of Continuous RGB and LWIR Perception on Embedded Devices*.

[Źródło roboczego manuskryptu LaTeX](main.tex) zawiera tytuł, streszczenie, pytanie badawcze, plan metodologiczny, wynik główny i granice interpretacji. [Pierwotny materiał badawczy](https://github.com/MatPomGit/arc-rgbt/blob/main/publications/P03/protocol/README.md) pozostaje źródłem szczegółowych założeń i protokołu.

Przypisanie do katalogu programu nie zmienia statusu zatwierdzenia ani nie stanowi potwierdzenia wykonania badań.
