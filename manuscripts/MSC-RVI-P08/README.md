# MSC-RVI-P08: Walidacja terenowa autonomicznej inspekcji względem inspekcji manualnej

Walidacja porównuje wykonanie i kompletność udokumentowanej misji robota z inspekcją manualną.

**Status naukowy:** planowany manuskrypt (`PLANNED`). **Tytuł angielski:** *Experimental Evaluation of Autonomous Humanoid Robots for Standardized Visual Documentation*.

[Kanoniczny manuskrypt LaTeX](https://github.com/MatPomGit/arc-rvi/blob/main/papers/paper08/manuscript.tex) jest utrzymywany w repozytorium projektu źródłowego. Nie powiela się jego źródła w indeksie programu ARC Robo.

Przypisanie do katalogu programu nie zmienia statusu zatwierdzenia ani nie stanowi potwierdzenia wykonania badań.
